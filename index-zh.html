軟件工程師 — 電話路由、雲端整合及安全工程 · eSOON China Limited

2026 年 5 月 – 2026 年 12 月 · Java（Spring Boot）· Python · Vue.js · Genesys Cloud · Terraform · Nginx

  • 使用 Spring Boot、Vue.js 及 Genesys Data Tables 建立全棧 Outbound Caller-ID 與 SBC 設定管理平台，為 AudioCodes Mediant SBC 自動化 INI 規則增量生成、版本快照、回滾及故障安全備份。
  • 使用 Terraform（CX as Code）及 Java/Vue 工具建立多環境 Genesys Cloud 遷移及依賴掃描流程，自動化跨組織資源部署及漂移驗證。
  • 開發多執行緒 Python CLI 自動化工具，用於 AudioCodes IP 電話配置、設定驗證、差異報告及 Genesys Cloud 稽核紀錄提取。
  • 使用 Architect Flow、DNIS、IVR、Data Tables 及交換器路由邏輯設計及部署高可用 Genesys Cloud 聯絡中心流程，並將虛擬機託管應用程式整合至 Nginx 反向代理後方。
  • 主導跨租戶安全漏洞事件回應，透過稽核日誌取證重建攻擊路徑，處理未授權 OAuth 憑證濫用、權限提升及後門持久化問題。
  • 在電話騙局事件中阻截超過 90 個欺詐國際電話，並透過 IP 允許清單及僅限 SSO 登入強化平台存取控制。
