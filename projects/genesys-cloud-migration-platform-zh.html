Genesys Cloud 多環境遷移及依賴分析平台

一個跨組織遷移平台，以 Terraform 同步 Genesys Cloud 資源，涵蓋依賴掃描、結構化差異審核、 核准控制、分層部署、回滾及稽核證據。

返回項目 原始碼為私人專案 — 不公開存放庫
核心貢獻：建立資源發現、Terraform HCL 生成、依賴閉包、漂移驗證及受控部署於同一條工作流。

項目概覽

私人企業項目 · Java、Vue.js、Terraform CX as Code 及 Genesys Cloud

平台提供兩種遷移入口：操作員建立的遷移任務，以及定時自動同步。 兩種入口共用同一個任務引擎及狀態模型；定時任務只會在 Plan 階段完成後跳過人工審批。 系統以跨組織資源部署、依賴安全執行及可追溯恢復為設計目標。

  • 加密儲存 OAuth 憑證，支援生產環境識別及只讀連通性檢查。
  • 支援多類 Genesys Cloud 資源的庫存瀏覽及快照基準建立。
  • 實作 Terraform 資源映射及 HCL 生成，隨後執行 init → plan → show及結構化差異解析。
  • 支援依賴圖閉包、欄位級審核、分層 Apply、暫停/恢復及快照回滾。
  • 提供 CSV、使用者對比報告、終端日誌及稽核紀錄。

兩種執行入口
  • 手動遷移任務：選擇資源、設定執行計劃、審核差異及依賴、確認後再 Apply。
  • 定時遷移：Plan 完成後由定時器建立及執行任務，無需人工審批。
  • 兩種入口共用同一任務模型，並限制每個目標環境只允許一組未完成任務。

工程重點

Terraform 編排

由 SDK 模型生成 Terraform 資源，在隔離工作區執行，並把狀態及差異解析為結構化證據。

依賴安全

透過 Flow YAML 引用掃描、資源註冊、圖形解析及範圍驗證，避免不完整或無效的跨組織遷移。

安全控制

憑證靜態加密、HCL 不寫入敏感值、生產環境 Apply 需短效驗證碼。

運作恢復

支援快照回滾、分層暫停、恢復及略過錯誤，以處理部分完成或中斷部署。
