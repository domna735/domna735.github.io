Genesys Cloud Migration & Dependency Platform

A cross-organisation migration platform that synchronises Genesys Cloud resources through Terraform, dependency scanning, structured diff review, approval controls, staged apply, rollback, and audit evidence.

Back to projects Source code private — no public repository
Core contribution: built the automation workflow that joins resource discovery, Terraform HCL generation, dependency closure, drift validation, and controlled deployment across source and target environments.

Project overview

Private enterprise implementation · Java, Vue.js, Terraform CX as Code, and Genesys Cloud

The platform provides two migration entry points: operator-created migration tasks and scheduled automatic synchronisation. Both share one task engine and state model, while scheduled tasks bypass manual approval only after the plan stage is complete. The implementation is designed for cross-organisation resource deployment, dependency-safe execution, and traceable recovery.

  • Encrypted OAuth credentials with production environment identification and read-only connectivity checks.
  • Resource inventory and snapshot baseline generation across supported Genesys Cloud resource types.
  • Terraform mapping and HCL rendering, followed by init → plan → show and structured diff parsing.
  • Dependency graph closure, field-level review, staged apply, pause/resume controls, and snapshot rollback.
  • CSV and user-comparison reports, terminal logs, and audit records for operational evidence.

Two execution entry points
  • Manual migration task: select resources, configure execution, review the diff and dependencies, confirm, and then apply.
  • Scheduled migration: the scheduler creates and executes the task automatically after plan generation, with no manual approval step.
  • Both entry points use the same task model and enforce one active task group per target environment.

Engineering highlights

Terraform orchestration

Terraform resources are generated from SDK models, executed in isolated workspaces, and parsed into structured state and diff evidence.

Dependency safety

Flow YAML references, resource registration, graph resolution, and scope validation prevent incomplete or invalid cross-organisation migrations.

Security controls

Secrets are encrypted at rest, credentials are not written into HCL, and production apply requires a short-lived verification code.

Operational recovery

Snapshot rollback, layer pause, resume, and skip-error handling support safe recovery from partial or interrupted deployments.
